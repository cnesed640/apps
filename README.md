# 충남교육청 중등교육과 공개 페이지

중등교육과 직원이 Claude로 만든 페이지를 학교·교사에게 공개하는 저장소입니다.
직원은 이 저장소를 직접 다루지 않습니다. 「중등교육과 웹 배포 신청함」에 HTML을 내면, 담당자가 검토·승인한 뒤 `tools/deploy.py`로 반영합니다.

- 페이지 주소: `https://cnesed640.github.io/apps/<주소이름>/`
- 페이지는 저장소 맨 위 `<주소이름>/` 폴더에 있고, 폴더마다 `meta.json`에 제목·팀·담당자·대상·게시 기간·변경 이력이 남습니다.
- 첫 화면(`index.html`)과 `catalog.json`은 배포할 때마다 자동으로 다시 만들어집니다. 손으로 고치지 마세요.
- 대상이 '학교·교사'인 페이지에는 검색 노출 막기(noindex)가 들어갑니다. 주소를 아는 사람은 누구나 볼 수 있으니 개인정보·내부 자료는 올리지 않습니다.

문의: 중등교육과 중등교육팀

`tools/`는 배포 스크립트 폴더입니다. tools, assets, apps, index, catalog, readme, admin, api, static은 주소 이름으로 쓸 수 없습니다.
